# 安全与隐私设计

## 1. 数据边界

| 数据 | 默认处理 |
|---|---|
| 遥控器音频 | 仅在进程内存和 PipeWire 中流动，不写文件、不上传 |
| 识别文本 | 只由 Superwhisper 处理；本守护进程不读取、不记录 |
| 蓝牙地址 | 可用于本机固定设备配置；日志默认脱敏 |
| 设备名称、固件和能力 | 可用于本地诊断，不包含语音内容 |
| Superwhisper 凭据和历史 | 不读取、不复制、不修改 |
| 配置与映射 | 当前用户私有，文档示例不得包含真实个人数据 |

本项目自身没有云端识别功能。Superwhisper 选择云端或离线由用户在其界面中决定；项目不得根据可用性、延迟或错误静默切换。

## 2. 权限最小化

- 使用用户级 BlueZ、PipeWire 和 systemd，不请求常驻 root。
- evdev 规则只覆盖目标设备，不授予所有输入节点的不必要写权限。
- uinput 能注入任意按键，属于敏感能力；规则和虚拟设备归属必须可审查。
- 不读取物理键盘，不记录全局输入，不实现键盘记录功能。
- 第一版不提供任意 shell 命令动作；后续应用启动使用 argv 白名单，不经过 shell。

项目不能防御已经拥有 root 或同用户完全控制权的攻击者，但必须避免把设备调试权限扩展成不必要的数据收集能力。

## 3. 故障安全

- 断连、崩溃、SIGTERM 和服务停止时释放 F9 及其他持续按键。
- 音频会话异常结束后不重复播放缓存，不保留上一段 PCM。
- 电源键默认不执行高风险动作。
- 不自动按 Enter，不自动批准 AI 操作，不自动接受修改。
- 配置错误或身份不确定时失败关闭，不猜测设备、不强行连接。

## 4. 隐私功能边界

- 无遥测、无使用统计上传、无崩溃内容上传。
- 无语音历史、回眸、后台监听或锁屏自动解锁。
- 无默认调试 WAV；如未来提供，必须单独显式启用并提示敏感风险。
- 不根据前台应用读取文档、输入框文本或周围上下文。

## 5. 供应链与许可

- 优先使用发行版包管理器和锁定的 Cargo 依赖。
- 复用 MIT 代码时保留许可与署名；`rctool` GPL 源码在当前许可策略未定前不复制。
- 发布资产提供 SHA-256，构建与安装脚本不下载未固定版本的二进制。
- 测试 fixtures 使用合成协议帧和合成音频，不包含真实用户语音。
- 文档、issue 和诊断输出在分享前检查设备地址、个人路径、语音和文本。
